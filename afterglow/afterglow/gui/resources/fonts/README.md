# Bundled fonts

Loaded at startup (`afterglow/gui/fonts.py`) so text in the Advanced
Editor looks the same on every machine. A deliberately small, varied set --
each one looks clearly different. All are free to redistribute; each
font's license is in `licenses/` (SIL Open Font License 1.1 or Apache 2.0),
all from https://github.com/google/fonts.

| Style      | Fonts |
|------------|-------|
| Comic      | Comic Neue, Bangers, Luckiest Guy, Patrick Hand, Permanent Marker |
| Serif      | Tinos (metrically compatible with Times New Roman), Playfair Display, Cinzel |
| Sans       | Roboto, Montserrat, Oswald, Anton, Bebas Neue |
| Typewriter | Courier Prime, Special Elite |
| Script     | Pacifico, Caveat, Lobster |
| Novelty    | Press Start 2P, Creepster, Orbitron |

Back Issues (Blambot) is the preferred speech/thought bubble font but its
license doesn't allow bundling it; when it's installed on the system it
is used automatically and listed first.
